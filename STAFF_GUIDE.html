Rodina Club

Гайдлайн для персонала  ·  Версия: июнь 2025

Что это

Rodina Club — система учёта подписок через Telegram Mini App.

  • Гость открывает бот @rodinasubbot → видит QR-код и свои остатки
  • Персонал сканирует QR → списывает кальян
  • Администратор управляет подписками, смотрит статистику, правит вручную
Приложение работает 24/7 на сервере — не зависит от чьего-либо ноутбука.

Как войти (персонал)

  1. Открыть @rodinasubbot в Telegram
  2. Нажать Start → кнопку «Открыть приложение»
  3. Система определит тебя автоматически через Telegram-аккаунт
  4. Если видишь гостевой экран вместо админки — сообщи администратору

QR-код гостя

QR-код есть у каждого зарегистрированного гостя — всегда, независимо от того, есть у него подписка или нет. Гость показывает QR, ты сканируешь.

Если гость не может найти приложение: он должен написать боту @rodinasubbot → Start.

Основное действие: списание

1. Сканировать QR

Нажать «Сканировать QR-код» в Админ-панели → поднести камеру к телефону гостя.

Или ввести ID вручную в поле под кнопкой (если камера не работает).

2. Выбрать тип списания

КнопкаЧто списывает
🌿 КальянОдин стандартный кальян с подписки
🍉 Фруктовая чаша−1 кальян и −1 фруктовая чаша одновременно
💰 350 RSDКальян за 350 RSD (раз в посещение)
⚡ Электронная чашаЭлектронная чаша (раз в посещение)

Если баланс равен 0 — кнопка неактивна, система не даст списать.

Заморозка

Если у гостя активна заморозка — в карточке показан замок 🔒. Списание заблокировано до её окончания.

Карта лояльности

Карта лояльности — только для гостей без активной подписки. Если подписка активна — карта не показывается и марки не ставятся.

  • Каждое посещение без подписки → кнопка 🌿 +1 марка за посещение
  • 10 марок = бесплатный кальян за 350 RSD
  • При накоплении 10 марок → кнопка «Погасить — кальян за 350 RSD»
  • После погашения счётчик сбрасывается в 0, история сохраняется

Отменить подписку

Кнопка «Отменить» → все остатки (кальяны, фруктовые и пр.) сгорают. Гость возвращается к системе марок лояльности.

Заморозить подписку

Кнопка «Заморозить» → указать количество дней. Размораживается автоматически по истечении срока.

Сменить план

Кнопка «Сменить план» → выбрать новый уровень. Остатки меняются на остатки нового плана.

Ручная корректировка

Прямое изменение числа кальянов в карточке гостя. Используй для исправления ошибочных списаний — в логе запишется «Корректировка».

Статистика

Главная страница Админ-панели показывает:

  • Всего гостей и активных подписок прямо сейчас
  • Списания за всё время — суммарно по каждому типу
  • По уровням подписок — активные и все когда-либо проданные
  • Последние 7 операций — с именами гостей и сотрудников

Выгрузка отчётности только Администратор

Кнопка «Выгрузить отчётность» на главной → открывается HTML-страница:

  • Сводка — кальяны, активации, марки и т.д. за всё время
  • Полная таблица — каждая операция с датой, гостем, сотрудником

Сохранить как PDF: нажать кнопку «Сохранить / Распечатать» → «Сохранить PDF».

Частые ситуации

Случайно списали лишнее.
→ Карточка гостя → Ручная корректировка → прибавить нужное количество обратно.

Гость хочет поменять тариф.
→ Карточка гостя → «Сменить план».

Гость хочет приостановить подписку на время поездки.
→ Карточка гостя → «Заморозить» → указать количество дней.

Гость потерял Telegram-аккаунт.
→ При восстановлении Telegram все данные вернутся — они привязаны к Telegram ID.

Бот не отвечает на /start.
→ Написать администратору — возможно, сервер обновляется.
